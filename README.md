# Disaster Zone: Siaga Bencana

Game edukasi kebencanaan untuk anak SD.

## Fitur

- 4 skenario bencana: Gempa, Erupsi, Tsunami, Banjir
- Prosedur resmi BNPB, BMKG, BPBD Manado
- Multiplayer real-time (Socket.IO)
- RPG 2D dengan karakter bergerak
- Chat in-game + emote
- NPC guru dengan dialog bercabang
- Simulasi gempa DROP-COVER-HOLD ON
- Dashboard guru real-time
- Login OTP email + Cloudflare Turnstile
- PWA + APK Android
- Dark mode + Sound BGM

## Teknologi

- Frontend: HTML5 Canvas, Vanilla JS, CSS3
- Backend: Node.js, Express, Socket.IO
- Database: SQLite
- Auth: Email OTP + Turnstile
- Deploy: Nginx + Cloudflare Tunnel
